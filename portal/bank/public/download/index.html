📋 Guide d'installation

1

Télécharger l'APK

Cliquez sur "Télécharger l'APK" ci-dessus depuis votre téléphone Android. Assurez-vous d'être connecté au réseau.

2

Autoriser les sources inconnues

Allez dans Paramètres → Sécurité → Sources inconnues et activez l'option pour permettre l'installation.

3

Installer l'APK

Ouvrez le fichier téléchargé depuis le gestionnaire de fichiers et suivez les instructions d'installation.

4

Se connecter

Lancez l'application CPlus et connectez-vous avec vos identifiants marchand. L'app se synchronise automatiquement.

5

Activer le NFC

Vérifiez que le NFC est activé sur votre appareil : Paramètres → Connexions → NFC. Indispensable pour le Tap to Phone.
